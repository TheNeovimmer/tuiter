API explorer for Neovim

Write requests in .http files, send them with one key, read the response in a floating window — with a Telescope-powered request browser, collections runner, history, environments, dynamic variables, and JSON pretty-printing. Pure Lua, zero deps, Neovim-native.

Installation

Requirements

  • Neovim >= 0.10 (uses vim.system, window titles, vim.json)
  • curl on PATH

LazyVim / lazy.nvim

{
  "TheNeovimmer/tuiter",
  branch = "main",
  dependencies = {},
  cmd = { "Tuiter", "TuiterRun", "TuiterRunAll", "TuiterCancel",
          "TuiterSaveBody", "TuiterHistory", "TuiterEnv", "TuiterResponse",
          "TuiterCopyAs", "TuiterStream", "TuiterWatch", "TuiterJUnit",
          "TuiterCI", "TuiterScaffold", "TuiterFormat", "TuiterImportPostman",
          "TuiterImportOpenapi", "TuiterImportCurl", "TuiterCollection",
          "TuiterSnippet" },
  ft = { "http", "graphql" },
  opts = {},
}

Usage

Open a .http file and press <leader>il for the request sidebar, or put the cursor on a request and hit <leader>is:

### Get users
GET https://jsonplaceholder.typicode.com/users
Accept: application/json

### Create user
POST https://jsonplaceholder.typicode.com/users
Content-Type: application/json

{
  "name": "ada"
}

Commands

:Tuiter Toggle request sidebar
:TuiterRun [lnum] Send request under cursor
:TuiterRunAll Run all requests, show summary
:TuiterCancel Cancel in-flight requests
:TuiterSaveBody Save last response body to a file
:TuiterHistory Pick a past request and re-run it
:TuiterEnv Select environment
:TuiterResponse Toggle response window
:TuiterCopyAs [lang] Copy request as code snippet
:TuiterStream Stream SSE request
:TuiterWatch [sec] Re-run request every N seconds
:TuiterJUnit [path] Export results as JUnit XML
:TuiterCI Run all + exit non-zero on failure
:TuiterScaffold Open a scaffolded .http buffer
:TuiterFormat Pretty-print request body JSON
:TuiterImportPostman [file] Convert Postman collection to .http
:TuiterImportOpenapi [file] Convert OpenAPI spec to .http
:TuiterImportCurl Paste curl command → new .http buffer
:TuiterCollection [new|add|list] Manage request collections
:TuiterSnippet [list|save|insert] Manage request templates

Keymaps

Default keymaps in .http files (<leader>i group):

<leader>is / <CR> Send request under cursor
<leader>il Request picker (Telescope)
<leader>ia Run all requests
<leader>ic Cancel in-flight requests
<leader>ik Keymap help float
<leader>ih Request history (Telescope)
<leader>ie Select environment (Telescope)
<leader>iv Show resolved variables
<leader>ir Toggle response window
<leader>iq Command picker (Telescope)
<leader>it Template picker (Telescope)
<leader>ib Collection picker (Telescope)
]r / [r Next / previous request
gx Open request URL in browser

Telescope Pickers

All browsing via Telescope with fuzzy finding, multi-select, and smart sorting.

Requests

:Telescope tuiter requests — browse requests in buffer, send, go to file, favorite, copy curl/code

History

:Telescope tuiter history — replay past requests, delete, copy curl

Environments

:Telescope tuiter env — switch between environments

Collections

:Telescope tuiter collections — browse collections, open requests inside, create/delete

Templates

:Telescope tuiter templates — insert built-in or saved templates, save current request

Commands

:Telescope tuiter commands — quick access to every tuiter command

Request picker actions

<CR> Send request
<C-o> Go to request in file
<C-f> Toggle favorite
<C-s> Copy as curl
<C-c> Copy as code snippet
<Tab> / <S-Tab> Multi-select
<C-a> Run all selected

Filter syntax

method:GET — filter by method

tag:auth — filter by tag

fav:true — filter favorites only

Collections & Templates

Collections

Organize requests in *.http.collections/ directories. Collections are git-friendly and can have their own env files.

:TuiterCollection new my-api    # create my-api.http.collections/
:TuiterCollection add           # add current file to a collection
:TuiterCollection list          # list all collections

Collection-specific env files (collection.env.json) override root-level env files.

Templates

Save and reuse request patterns. Built-in templates include GET, POST, PUT, DELETE, auth, pagination, GraphQL, health check, and login flow.

:TuiterSnippet list             # show all templates
:TuiterSnippet save my-template # save current request as template
:TuiterSnippet insert           # insert a template at cursor

Request Tags

Tag requests for filtering:

### Login
# @tag auth,critical
POST https://api.example.com/login
Content-Type: application/json

{"email": "user@example.com", "password": "secret"}

Filter by tag in the sidebar: tag:auth shows only requests tagged with "auth".

Configuration

{
  opts = {
    keymaps = {
      run = "<leader>is", list = "<leader>il", run_all = "<leader>ia",
      cancel = "<leader>ic", help = "<leader>ik",
      history = "<leader>ih", env = "<leader>ie", response = "<leader>ir",
      vars = "<leader>iv", browser = "gx",
    },
    curl = { timeout = 30, insecure = false, max_redirects = 8, cookie_jar = true, compressed = true },
    env_files = { "http-client.env.json", "tuiter.env.json" },
    default_env = "default",
    run_all = { concurrency = 1, delay = 150 },
    windows = {
      layout = "float", -- "float" or "split"
      response_side = "right",
      width = 120, max_height = 40, sidebar_width = 62,
    },
  },
}
